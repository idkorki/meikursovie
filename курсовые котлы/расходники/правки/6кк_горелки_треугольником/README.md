# 6кк (вар. 9): горелки треугольником вершиной вниз — пересчёт

По 3 горелки на каждой боковой стене: внизу 1, вверху 2 (nниж = 2, n2 = 4).
Средняя высота горелок взвешена по числу горелок: (2·1,70 + 4·3,825)/6 = 3,117 м (было 2,763).

Факел выше → чтобы ϑ″т ≤ 980 °С, высота топки 17,75 → 18,30 м (шаг 0,05 м), Vт 947,0 → 982,1 м³, Fст 678,2 → 696,4 м².
Дальше: Qш.л 1 083,5 → 1 055,2; t″шпп 435,01 → 433,99 °С; ϑ″гп 570,0 → 567,6; ϑ″хп 422,4 → 419,2 °С;
ГПП 3 017 → 3 120 м² (40 → 42 ряда), ХПП 2 356 → 2 431 м² (35 → 36 рядов), экономайзер 484 → 463 м², t″эк 235,15 → 234,16 °С.
ϑ″эк = 352,9 °С и ТВП не меняются (H″эк = Qт − Qрηпк/100). Объём 906,5 м³ по поверочному расчёту — 1 039 °С (было 1 011).
