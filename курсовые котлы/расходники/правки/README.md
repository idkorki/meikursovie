# Правки готовых записок без генератора (облачные сессии Claude, 2026-11-26)

Генератор курсовых по котлам (`расчёты/кк`, `расчёты/кк2`) лежит только на компьютере пользователя
(`~/работы мэи/курсовые котлы/расходники/расчёты/`). Когда его нет, записку правят прямо в docx –
общий модуль `инструменты/pravki.py` в корне репозитория (скилл `mei-pravki-docx`).

| Папка | Работа | Что сделано |
|---|---|---|
| `6кк_горелки_треугольником/` | 6кк, вар. 9 | горелки по 3 на боковых стенах треугольником вершиной вниз; полный пересчёт: hгор 3,117 м, hт 18,30 м, Vт 982 м³, ширмы, КПП, ЭК, табл. 5, рис. 3, 4. `furnace.py` + `chain.py` – модель БКЗ-210 от конструктивного расчёта топки до экономайзера (IAPWS-97), на старых данных воспроизводит записку |
| `2кк_подробный_поверочный/` | 2кк, вар. 33 | п. 3.11 расписан на 3,5 с. (два приближения 1075/990 °С), табл. 5 и 6, бывшая 5 → 7 |
| `9кк_подробный_поверочный/` | 9кк, вар. 31 | то же, одно приближение (1030 °С), свой текст |
| `12кк_подробный_поверочный/` | 12кк, вар. 43 (ТФ-01-24, прислан готовым) | то же, два приближения (1110/1005 °С), свой текст |

Скрипты здесь – запись того, как делалось: пути в них указывают на временные папки сессии, повторно
запускать их не нужно. `part.py` – блоки текста раздела (полезно как образец формулировок и формул).
Для новой правки: `инструменты/pravki.py` (Doc.replace_section, fix_toc, build_pdf).
