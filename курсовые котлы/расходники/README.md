## Сборка работы (с 2026-10-22)

**Свой текст работы (2026-10-29).** Работы одного потока сдаются одному преподавателю, поэтому текст записки у каждой
свой, как у курсовых по теплу и расчёток: не больше 25 % совпадения фраз с любой другой работой.

  и не выдумываются);
- `python3 uniq.py <записка.docx>` - совпадение с остальными работами `курсовые котлы/*кк`, FAIL - не отдавать.
