# Методички и литература по работам МЭИ

Все методички, учебники и образцы по расчётным работам (физика, теплотехника, механика) лежат здесь,
по одной папке на предмет. Информатика (папки `~/поштет`, `~/даня`, `~/projects`) сюда не входит.

Старые места оставлены ссылками, чтобы скрипты сборки не сломались:
- `курсовые тепло/расходники/материалы` → `теплоснабжение/` (её ищут скилл kursovaya-teplosnabzhenie и 3к);
- `курсовые котлы/расходники/материалы` → `котлы/`;
- `курсовые механика/расходники/материалы` → `прикладная механика/`.

## теплоснабжение/
Курсовая «Теплоснабжение жилого района от ТЭЦ» (Чугунков Д.В.), `~/работы мэи/курсовые тепло/`.
- `Методические_указания_Чугунков_Д_В_1.pdf` — методичка, по ней весь расчёт (скан; П-1 стр. 36, П-2/П-3 стр. 37–40).
- `Ашитко_М_М_Курсовая_работа_Теплосети.pdf` — образец чужой работы (оформление не по ГОСТ, не брать).
- `чужие_расчёты_яндекс/` — чужие курсовые в Mathcad (.xmcd/.mcd), графики, титульник. Только для сверки.

## котлы/
Курсовая «Тепловой расчёт котла ТГМП-314А», `~/работы мэи/курсовые котлы/`.
- `Липов, Третьяков. Кот.уст.и ПГ 2003.pdf` — учебник «Котельные установки и парогенераторы» (скан, 588 с.;
  номер страницы PDF = страница книги − 1). Таблиц составов топлив нет.
- `ТЭЦ МЭИ. Методичка.pdf` — описание оборудования ТЭЦ МЭИ (скан).
- `Лабник0001.pdf` — Липов и др., «Испытания оборудования котельного отделения ТЭЦ МЭИ», лабораторный практикум (скан).
- `Расчет_топочной_камеры_Липов_Ю_М_,_Семин_С_А_.pdf` — методичка к расчётке «Расчёт топочной камеры» (МЭИ, 2012), текстовая; табл. 1–5 зашиты в генератор `расчетки мэи/расходники/расчёты/топка`.
- `Образец_КР_ТГМП-314А_газ.pdf` / `.docx` — чужая курсовая по этому же заданию (ТГМП-314А, Dп = 278 кг/с, газ
  Саратов–Москва, rг = 0,08), добавлена 2026-10-22. Полная цепочка расчёта с числами: исходные данные и присосы,
  КПД и расход топлива, конструктивный и поверочный расчёт топки, ширмы, поворотная камера, КПП ВД, КПП НД,
  экономайзер, РВП (невязка 0,0023 %). Титула, введения, списка литературы и чертежей нет, начинается с «Раздела 2».
  Ссылки: [1] — видимо, Липов 2001 (у нас нет), [2] — WaterSteamPro. Нестыковка: в табл. 2.1 Dвпр = 12 кг/с,
  в расчёте ΣDвпр = 21 кг/с. Использовать для сверки хода расчёта и порядка величин, текст не брать. Принята ли
  преподавателем — неизвестно.
  Это образец потока ТФ-06/07 из Telegram: `курсач_котлы.pdf/.docx` — тот же файл (md5 совпадает).
- `Образец_КР_БКЗ-210-140Ф_уголь_Ляпин.docx` — чужая курсовая групп 1–2 (Ляпин А.А., ТФ-01-23, вар. 36), образец для 2кк
  (до 2026-10-24 назывался `e74a45071ae355059d10c0deeded36c7.docx`).
- `Липов1988_табл_П4.1_угли_фото.jpeg`, `Липов1988_табл_П4.2_угли_фото.jpeg` — фото таблиц углей из Липова 1988
  (были `Untitled.jpeg`, `Untitled1.jpeg`).
- `Сводная_таблица_результатов_расчёта_котла_бланк.png` — бланк итоговой таблицы курсовой по котлу (ТК, ШП, КПВД).
- `ПЗ_2_ТФ_07_24_Показатели_топок_задания_РТ.pdf` — слайды ПЗ-2 Зройчикова со списком 26 вариантов расчётки
  «Расчёт топочной камеры» (все варианты уже зашиты в `расчетки мэи/расходники/расчёты/топка/calc.py`).
- `Tipovoy_2_po_Goreniyu.xmcd` — типовой расчёт № 2 по горению угольной пыли (ТФ-02-19), справочно.

Методика Липова–Семина — основа расчётки «Расчёт топочной камеры» (`расчетки мэи/`); нужные её таблицы уже зашиты в генератор `расходники/расчёты/топка`.

- `Липов_Компоновка_и_тепловой_расчет_парового_котла_1988.djvu` — Липов Ю.М., Самойлов Ю.Ф., Виленский Т.В.
  «Компоновка и тепловой расчёт парового котла», 1988, 108 с. (скан, без текстового слоя).
- `Расчет_Курсач_Котлы.docx` + `Универсиальный_расчет_Курсач_Котлы.sm` (SMath Studio 1.3) — решение для групп
  ТФ-01/02 (ТЭЦ), добавлено 2026-10-22: тот же ТГМП-314А, но только топка (баланс, КПД, тепловыделение,
  поверочный расчёт топки, тепловосприятие экранов НРЧ/СРЧ/ВРЧ). Топливо по Кузнецову «Нормативный метод»
  (табл. IV, XIII, XVI); в «рыбе»: Qн = 35 590, tух = 125 °С, tхв = 25 °С, rг = 0,1, q3 = 0,15, tгв = 313,5 °С.
  В docx формулы — объекты Word, текст без чисел. Для 1кк (ТФ-06/07) не использовать.
- `консультации Пай/` — консультации ст. преп. Пая А.В. по курсовой ТГМП-314А (курс «Энергетические котлы
  и системы теплоснабжения»), со слов пользователя нужны для групп ТФ-01/02 (2026-10-22):
  1 — требования, задание, цели КР, котлы СКД; 2 — описание котла ТГМП-314А; 3 — газо-воздушный тракт, выбор исходных данных;
  4 (`4_kons.pdf`) — водо-паровой и топливный тракт, горелки; 5_1 — тепловой баланс, габариты топки;
  6 — поверочный расчёт топки; 7 — итоговые параметры сред и топки, чертежи; 8 — оформление РПЗ и чертежей,
  защита.

Нет и нужно для варианта 12: Липов Ю.М. «Тепловой расчёт парового котла» (2001) — табл. 2.2/2.3 топлив и методика;
методичка Липова–Семина уже есть (см. выше).
