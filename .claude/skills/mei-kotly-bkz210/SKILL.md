## Модель расчёта (для пересчёта без генератора)

`курсовые котлы/расходники/правки/6кк_горелки_треугольником/furnace.py` и `chain.py` воспроизводят 6кк;
константы варианта (B, Qт, Ta, Vр, Fр, hт.р, Ар, энтальпии) взять из записки. Цепочка:
- **Топка, конструктивный (п. 3.10):** bт = 6dа·φя = 6,12; aт = 1,7bт = 10,404; ψ = 0,45·(1 − 0,2(s/d − 1)) = 0,4203;
  hниж = 2dа = 1,70, h2 = hниж + 2,5dа = 3,825; hгор – среднее ярусов (**взвешенное по числу горелок**, если ярусы
  неравные); h′т = hт − h′го/2; Xт = hгор/h′т; M = 0,59 − 0,5Xт; S = 3,6V/F; kг = 0,92(4/S)^0,54·1470/T″,
  kзл = 2,96(Ар/35)^1,33(1470/T″)^0,67, kк = 0,2; εф = 1 − e^(−k·0,1·S); εт = εф/(εф + (1 − εф)ψ);
  qF = εтψTа²/N·(M/(1 − Θ))^1,67, N = 9200; Fт = BQт/qF; Δh = 0,5ΔF/(aт + bт); V = Vр + Δh·aт·bт.
  Объём не меньше Vмин = BQрн/175. Если поверочный ϑ″т > t1 − 20, высота призматической части растёт
  (шаг 0,05 м) до ϑ″т ≤ t1 − 20.
- **Поверочный (п. 3.11):** ϑ″ = Ta[1 − M(εтψTа²/(N·qF))^0,6] − 273, qF = BQт/Fст; повтор, пока |Δϑ| > 30 °С
  (k при Vмин – итерация по T″ = ϑ″ + 273: так получены «1 011 °С» 6кк).
- **Ширмы:** qл = BQл/(Fст·0,985), Qш.л = 1·0,8·qл·φш·Fш.л/B, φш = 1 + c/s − √(1 + (c/s)²), Δϑш = 140 °С,
  Δhш = B(Qш.л + Qш.б·zш/(zш + 1))/Dш.
- **Пар:** P по тракту 0,4/0,2/0,4 ΔP; ХПП +25 °С от ts; впрыски 5 % (60/40); Qл.вых = Qш.л(1 − φш)/φш;
  Qгпп = D(hпп − h′гпп)/B; Qхпп = Dхп(h″хпп − h′хпп)/B − Qл.вых.
- **КПП, ЭК:** k = 0,86ξA(w/9)^n…, пакеты коридорные (ГПП прямоток, ХПП противоток), ЭК замыкающий:
  Qэк = Qрη/100 − (Qл + Qш.б + Qгпп + Qхпп). H″эк от топки не зависит → ТВП не меняется.
- Свойства пара – iapws IAPWS97.

## Замечания преподавателей и как их делали

- «Горелки не встречно, а треугольником» (6кк): по образцу Ляпина – по 3 на боковых стенах «треугольником вниз»
  (внизу 1, вверху 2). Текст п. 2.3, 3.8, 3.10 + hгор взвешенная → полный пересчёт, эскиз (рис. 3) перерисован
  с тремя горелками, Q–t (рис. 4). Сначала спросить заказчика: только описание или с пересчётом.
- «Поверочный расчёт подробнее, на 3–4 листа» (2кк, 9кк, 12кк): см. `mei-pravki-docx`, раздел «Расписать подробнее».

## Чертёж

Отдельных листов-чертежей в этой работе нет (в образце их не было), только эскиз топки в записке. Требование
«2 листа разрезов котла» из консультаций Пая относится к ТГМП (`mei-kotly-tgmp`). Если ТФ-02 просят чертёж – это
работа по ТГМП-344 (см. там), уточнить у заказчика.
