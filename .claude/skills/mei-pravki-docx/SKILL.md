# Правка готовой записки в docx

Модуль: `инструменты/pravki.py` (импорт: `sys.path.insert(0, '<repo>/инструменты')`). Окружение: `инструменты/setup.sh`.

## Порядок

1. **Найти работу и прочитать README раздела** (`<раздел>/расходники/README.md`): вариант, особенности, что уже
   правилось.
2. **Разобрать docx:** `d = Doc(path); d.dump()` – блоки с номерами картинок (`#113` = `word/media/image113.png`).
   Формулы в записках – картинки, числа в них видны только глазами: собрать нужные в одну картинку и посмотреть
   (PIL: склеить `image*.png` раздела с подписями номеров).
3. **Воспроизвести расчёт раздела** скриптом (python) по формулам записки и убедиться, что старые числа совпадают
   (до округления). Без этого не менять ни одного числа. Скрытые точные значения (например ψ = 0,934·0,45 = 0,4203,
   B точнее, чем в тексте) подбирать так, чтобы старые результаты сошлись до последнего знака.
4. **Понять, докуда идёт каскад.** Пример (БКЗ-210): высота топки → F_ст → q_л → Q_ш.л → ширмы → КПП → Q_эк;
   но H″_эк = Q_т − Q_р·η/100 не зависит от топки, поэтому воздухоподогреватель не меняется. Найти в тексте все
   места со старыми числами: таблицы, текст, заключение, рисунки (Q–t-диаграмма, эскизы, пьезометр).
5. **Шаблоны формул проверить на старых значениях:** `formula_png(tex_old)` должен дать картинку той же ширины,
   что и исходная (до 1–2 px). Только потом рисовать новые. Сведения о стиле:
   - `\dfrac` для дробей нормального размера, `\frac` – для мелких (внутри показателей);
   - индексы – `\mathrm{...}`; «ш. л» в индексе пишется `\mathrm{ш.л}` (без пробела);
   - «°С» в конце – `DEG` (`\ ^{\circ}\;\mathrm{C}`), в части формул `DEG_THIN`; стрелка выбора – `\ \rightarrow\ `;
   - тысячи – `num(v, n)` → `19\ 508{,}2`.
6. **Внести правки:**
   - `d.replace_image(k, png)` – заменить формулу/рисунок (extent пересчитывается; для рисунков во всю ширину
     `keep_width=True`);
   - `d.replace_section(i_заголовка, i_следующего_заголовка, blocks)` – переписать раздел целиком:
     `('p', текст)`, `('f', tex)`, `('img', N)` (старая картинка), `('tbl', подпись, шапка, строки)`;
     в тексте `X_{т}` – нижний индекс, `A^{р}` – верхний;
   - `renumber_tables(d, start, shift)` – сдвинуть номера таблиц **до** вставки новых таблиц;
   - мелкий текст – `d.replace_text(old, new)` или python-docx по runs (индексы в тексте – отдельные runs
     с vertAlign).
7. **Собрать и проверить:** `pdf = build_pdf(docx)` → `fix_toc(docx, pdf)` → снова `build_pdf`. Затем
   `pdftoppm -r 70` по изменённым страницам и просмотр, `pdftotext | grep` старых чисел, число страниц.
8. Сохранить docx и pdf в папку работы (имена прежние), скрипт правки – в `<раздел>/расходники/правки/<работа>_<что>/`
   с README, дописать итог в README раздела, коммит + push, отправить файлы пользователю.

## «Расписать подробнее» (поверочный расчёт на 3–4 страницы)

Сделано для 2кк, 9кк, 12кк (`курсовые котлы/расходники/правки/*_подробный_поверочный/part.py` – образцы).
Состав раздела: вводный абзац (цель, критерий 30 °С) → таблица исходных данных → формула (7) → величины, не
зависящие от температуры (S, h′_т, X_т, M, q_F), каждая отдельной формулой с пояснением → для каждого приближения:
T″, k_г, k_зл, k, ε_ф, ε_т, комплекс Π и Π^0,6, ϑ″ (старая картинка), Δϑ → вывод → таблица результатов →
H″_т, Q_л, доля Q_л/Q_т, Q_экр = B·Q_л, q_экр. Числа не меняются. Таблицы после вставленных – перенумеровать,
содержание поправить. Текст каждой работы писать заново.

## Частые ловушки

- docx, присланный из Word, – те же блоки, но абзацы могут иметь другие pPr; шаблоны берутся из самого раздела.
- `replace_section` берёт шаблон абзаца и формулы из заменяемого раздела; если там только картинки – передать
  `tmpl_range` соседнего раздела.
- Короткие таблицы держатся целиком (keepNext) – внизу страницы может остаться пусто, ГОСТ это допускает.
- Свойства воды и пара – `iapws.IAPWS97(P=МПа, T=K)` (как WaterSteamPro в записках).
- Рисунки (эскиз топки – шрифт osifont, Q–t, пьезометр – Liberation Serif) перерисовывать matplotlib в тех же
  пикселях и dpi, что исходная картинка; сравнить со старой бок о бок.
