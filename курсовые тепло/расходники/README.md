# Служебная папка Claude

> Пути `~/курсовые/...` и `_claude/` ниже – старая раскладка на компьютере пользователя; сейчас это
> `~/работы мэи/курсовые тепло/` (папки работ `Nкт`) и `расходники/`. Генератор и скилл в репозиторий не выложены.
> Правки без генератора – `правки/` (3кт: напор 20–25 м, 2026-11-26).

Всё рабочее для курсовых «Теплоснабжение жилого района от ТЭЦ» лежит здесь.
В `~/курсовые/Nк/` остаётся только сама курсовая: задание (фото или PDF) и то, что отдаётся заказчику
(записка docx/pdf, Лист1/Лист2 А3, zip — в именах фамилия студента).

```
_claude/
  README.md            этот файл
  материалы/           методичка Чугункова (скан; П-1 стр. 36, П-2/П-3 стр. 37–40) и образец Ашитко
  ГОСТ/ПРАВИЛА_ОФОРМЛЕНИЯ.md   правила ГОСТ 7.32 / 7.0.100: что применяется, что нет, образцы
  расчёты/Nк/          папка работы
    новые работы (по эталону): variant.py (данные задания), text.py (текст ПЗ), рисунки/, img/f (кэш формул),
                       toc_pages.json, report.log. Код — в скилле: ~/.claude/skills/kursovaya-teplosnabzhenie/template
    1к–5к (до эталона): свои calc.py, figs.py, report.py, build.sh; 4к — эталон, её собирает и шаблон
```

Новая работа: `template/new_work.sh Nк`, заполнить variant.py и text.py, `template/build.sh ~/курсовые/_claude/расчёты/Nк`.
Процесс и проверки — в скилле `kursovaya-teplosnabzhenie`.

Дополнено 2026-10-22: `материалы/` теперь ссылка на `~/работы мэи/методички/теплоснабжение/` (там же оглавление всех методичек). В ней `чужие_расчёты_яндекс/` — чужие курсовые по теплоснабжению (Mathcad .xmcd/.mcd,
графики, титульник) из публичной папки «КОТЛЫ и ТЕПЛО» на Яндекс-диске. Только для сверки методов и чисел,
текст оттуда не брать. Сборкой не используются.
