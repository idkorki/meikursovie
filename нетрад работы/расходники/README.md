# Служебная папка: расчётное задание по НВИЭ («Солнечное теплоснабжение коттеджа»)

Курс «Нетрадиционные и возобновляемые источники энергии», кафедра ГВИЭ, проверяет Макеев А.Н. Работы – `Nнр/`.

- `материалы/` – всё с 4 QR слайда (1нр/Pasted image.png): задание (35 вариантов), справочные графики
  (скачивание на Диске закрыто – страницы сняты из просмотрщика 3200 px), вопросы к зачёту, темы презентаций.
- `расчёты/нвиэ/` – генератор: calc.py (f-метод Даффи–Бекмана), figs.py, report.py (оформление – kit.py курсовых
  по котлам), build.sh, `power_вар<N>.json` – климат NASA POWER для варианта.

Новый вариант N:
1. Данные варианта из задания – в `TASK` calc.py. Обе координаты – градусы и минуты, минуты > 59 переносятся в градусы
   (38°69′ = 39°09′, решение пользователя 2026-11-10). Наклон: dS = 5 (S = φ + 5°) или 0, если в задании S = φ (вар. 14).
2. Климат: `curl "https://power.larc.nasa.gov/api/temporal/climatology/point?parameters=ALLSKY_SFC_SW_DWN,ALLSKY_KT,T2M,HDD18_3,TOA_SW_DWN,SRF_ALB&community=RE&longitude=<λ>&latitude=<φ>&format=JSON" > расчёты/нвиэ/power_вар<N>.json`.
3. `KK_FORMULAS=<dir>/formulas.txt KK_STUDENT="Фамилия И.О." KK_GROUP="ТФ-0x-24" расчёты/нвиэ/build.sh N "<папка Nнр>" "РЗ_НВИЭ_<Фамилия>_вар<N>"`,
   затем `formulas.py <dir>` скилла тепла – 0 ошибок.
4. Текст пока общий для всех вариантов (числа подставляются): при второй работе того же потока переписать абзацы,
   как в курсовых (≤ 25 % совпадения).

Методика: нагрузка – (UA)L·D (HDD18_3) + ГВС; H̄d/H̄ – Эрбс (месячная); R̄b – Клейн для ψ = 0; θd, θr – формулы
справочных данных; θ̄b – осреднение по среднему дню с весом прямого излучения на наклонную площадку (сходится с
графиками справочных данных); (τα)/(τα)n – оцифрованная кривая 1 покрытия; F′R/FR, (V/75)^−0,25,
Yc/Y = 0,39 + 0,65·exp(−0,139/zL); f = 1,029Y − 0,065X − 0,245Y² + 0,0018X² + 0,0215Y³; F – взвешенная по L.
Допущения (в задании нет): ГВС 105 л/(чел·сут) – норма горячей воды в средние сутки по СНиП 2.04.01-85*, прил. 3 (в СП 30.13330.2020 такой цифры нет; в 4нр ссылка исправлена 2026-11-26, в остальных пока СП 30), ε промежуточного ТО 0,70, одно стекло, база 18,3 °С.
