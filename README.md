# Работы МЭИ (ТФ-01…07-24 и соседние группы)

Расчётные работы по теплотехнике: курсовые по теплоснабжению и котлам, типовые расчёты, РЗ по НВИЭ.
Информатика и механика сюда не входят (механика – `~/работы мэи/курсовые механика/` на компьютере пользователя).

| Папка | Что | Работы | Скилл |
|---|---|---|---|
| `курсовые тепло/` | «Теплоснабжение жилого района от ТЭЦ» (Чугунков) | `1кт`…`11кт` | `mei-teplosnabzhenie` |
| `курсовые котлы/` | БКЗ-210-140Ф, ТФ-01/02 (Чернов) | `2кк`, `6кк`, `9кк`, `12кк` | `mei-kotly-bkz210` |
| `курсовые котлы/` | ТГМП-314А, ТФ-06/07 (Пай, Апаров); ТГМП-344 ТФ-02 – пока не было | `1кк`, `3кк`–`5кк`, `7кк`, `8кк`, `10кк`, `11кк` | `mei-kotly-tgmp` |
| `расчетки мэи/` | «Расчёт топочной камеры» (Зройчиков) | `1р`…`13р` | `mei-raschetka-topka` |
| `нетрад работы/` | РЗ НВИЭ «Солнечное теплоснабжение коттеджа» (Макеев) | `1нр`…`9нр` | `mei-nvie` |
| `методички/` | вся литература, оглавление – `методички/README.md` | – | – |
| `инструменты/` | `pravki.py` – правка готовых docx без генератора, `fc.conf`, `setup.sh` | – | `mei-pravki-docx` |

Скиллы – `.claude/skills/` (Claude Code подхватывает их сам; начинать с `mei-raboty`).

## Порядок в папках

- **Папка работы** (`Nкт`, `Nкк`, `Nр`, `Nнр`) – только задание (фото, docx) и то, что отдаётся: записка docx + pdf,
  листы, zip. Имена файлов – как в первой сдаче, при правке не меняются.
- **`<раздел>/расходники/`** – всё рабочее: `README.md` (журнал работ, решения пользователя – читать перед правкой и
  дописывать после), `материалы` (ссылка на `методички/…`), `правки/` (скрипты правок без генератора).
- **Генераторы** (`расходники/расчёты/…`) и скилл `kursovaya-teplosnabzhenie` лежат только на компьютере
  пользователя (`~/работы мэи/…`, `~/.claude/skills/`), в репозиторий не выложены. В облачной сессии без них правки
  делаются в docx (`инструменты/pravki.py`).
- **Литература** – только в `методички/`.

## Общие правила

Числа не выдумывать (сначала воспроизвести записку), текст каждой работы свой (≤ 25 % совпадения с другими работами),
PDF – LibreOffice с `инструменты/fc.conf`, после правки сверить содержание и просмотреть страницы. Подробно –
`.claude/skills/mei-raboty/SKILL.md`.
