# Работы МЭИ (группа ТФ-07-24 и соседние)

Расчётные работы по физике, теплотехнике и механике. Информатика сюда не входит (`~/поштет`, `~/даня`, `~/projects`).

| Папка | Что | Работы | Как собирается |
|---|---|---|---|
| `курсовые тепло/` | «Теплоснабжение жилого района от ТЭЦ» (Чугунков) | `1кт`…`8кт` | скилл kursovaya-teplosnabzhenie, `расходники/README.md` |
| `курсовые котлы/` | тепловой расчёт котла: ТГМП-314А (ТФ-06) и БКЗ-210-140Ф (группы 1–2) | `1кк` (вар. 12), `2кк` (вар. 33) | `расходники/README.md` |
| `курсовые механика/` | «Прикладная механика», привод с червячным редуктором | `1км` (Власов, по Дунаеву), `2км` (Власов по схеме Коробова) | `расходники/расчёты/Nкм/build.sh` |
| `расчетки мэи/` | типовой расчёт «Расчёт топочной камеры» (Зройчиков) | `1р` Власов, `2р` Пахомов, `3р` Семенов | `расходники/расчёты/топка/build.py N` |
| `методички/` | вся литература по предметам | — | `методички/README.md` — оглавление |

Общее правило: в папке работы (`1кт`, `1кк`, `1км`, `1р`) лежит только задание и то, что отдаётся. Всё рабочее
(код, исходные, архивы) — в `расходники/` своего курса. Литература — только в `методички/`; в `расходники/материалы`
лежит ссылка туда.
