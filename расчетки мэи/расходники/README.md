## «Расчёт топочной камеры парового котла»

Дисциплина «Энергетические котлы и системы теплоснабжения», преподаватель Зройчиков Н.А., группа ТФ-07-24.
Методика — Липов Ю.М., Семин С.А. «Расчёт топочной камеры парового котла» (МЭИ, 2012). Таблицы методички и список
всех 26 вариантов группы (фамилия, D, параметры, топливо) уже зашиты в `calc.py`, внешние файлы не нужны.

Сборка варианта N:

```bash
cd "$HOME/работы мэи/расчетки мэи/расходники/расчёты/топка" && python3 build.py N
```

Результат — папка работы `<k>р/`: если работа этого варианта уже есть, пересобирается в своей папке
(ищется по имени записки `РТ_Топочная_камера_<Фамилия>_вар<N>.docx`), новая получает следующий номер
(`calc.work_dir`). Внутри — записка docx и pdf (номера страниц в содержании проставляются в два прохода,
последней страницей — векторный эскиз А2) и отдельно `Эскиз_топки_<Фамилия>_А2.pdf`. Рисунки — в `img/вар<N>/`.
Проверять в выводе calc.py флаги bt_in / kq_in / burn и смотреть страницы PDF глазами.

**Варианты другой группы.** Таблица с фото в `4р` (29 вариантов, без ФИО) внесена в `calc.py` как `VARIANTS_B`
с ключами `Б1`…`Б29`: `python3 build.py Б4`, текст — `тексты/варБ4.py`, `uniq.py Б4`. Пустые ФИО и группа дают
прочерки на титуле и в штампе, шифр `РТ.<номер>`, имена файлов без фамилии (`РТ_Топочная_камера_вар4.docx`).
Новая работа занимает заведённую пользователем папку `<k>р`, в которой ещё нет записки (там лежит только задание).
Источник этой таблицы — презентация ПЗ № 4 Зройчикова (`5р/Котлы.pdf`). В её табл. П5 глубина топки для D_п = 33–89 кг/с
4–8 м, в методичке 4,5–5,5 м: для ключей Б берётся 4–8 м (`calc.B_LOW`), в тексте ссылка «табл. П5 [3]».
5р – вар. 15 (Б15): 320 т/ч, антрацит, первая работа с ЖШУ. Для ЖШУ генератор рисует две лётки и футеровку (рис. 2а
методички), абзацы a91/a92 записки.

**Текст записки — уникальный для каждой работы** (как в курсовых по теплу; решение пользователя 2026-10-22).
Текст по умолчанию в report.py — это текст Власова (вар. 2, защищён на 5). Для новой работы пишется
`расчёты/топка/тексты/вар<N>.py`: функции a01…a89 (ключи абзацев report.py), каждый абзац своими словами,
числа — через R и n(), не руками. Абзацы варианта с ключами: `RT_KEYS=1 python3 report.py N` → img/keys_N.json.
report.py пишет в stderr, какие абзацы остались по умолчанию (допустимо только a90 — литература).
Проверка: `python3 uniq.py N` — не больше 25 % совпадения фраз с каждой из остальных работ (1р, 2р, ...), FAIL — не отдавать.

Требования: Times New Roman 12, интервал 1,5, поля 30/10/20/20, сдача в PDF; опечатка методички L3 = 0,75·L2.
